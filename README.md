# Portfolio - Darshan Makwana

A modern, fast, and fully responsive personal portfolio that showcases work, leadership, and contact details in a clean, professional layout. Built to be simple to navigate and easy to maintain.

## Live Site

- https://darshan-makwana-portfolio.vercel.app/

## Highlights

- Focused hero section that introduces me and my role at a glance
- Dedicated sections for About, Projects, and Leadership
- Streamlined contact experience for quick outreach
- Clean, readable layout with mobile-first responsiveness
- Lightweight, fast-loading Next.js App Router build

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- CSS (global styles)
- Vercel (deployment)

## Project Structure

- `src/app` - App Router pages, layout, and global styles
- `src/components` - Reusable UI sections (Hero, About, Projects, Leadership, Contact, Footer, Navbar)
- `public` - Static assets

## Notes

This repository is meant to present my portfolio to the public. If you want to collaborate or share feedback, feel free to reach out via the live site.
